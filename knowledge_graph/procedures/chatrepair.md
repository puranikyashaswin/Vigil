# ChatRepair

A fully automated conversation-driven Automated Program Repair (APR) approach that interleaves patch generation with instant feedback. It uses ChatGPT to perform repair in a conversational style, leveraging test failure information and learning from both failed and plausible patches. Achieves 114 and 48 correct fixes on Defects4j 1.2 and 2.0 respectively, fixing 162 out of 337 bugs for $0.42 each.
