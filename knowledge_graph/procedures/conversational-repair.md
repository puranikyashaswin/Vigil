# Conversational Repair

The core repair loop in ChatRepair where patch generation is interleaved with test validation feedback. Each generated patch is immediately validated; if it fails, feedback including the incorrect patch and failing test information is appended to the conversation to guide the next patch generation. Conversation length is bounded by a maximum conversation length hyperparameter.
