# Neural Machine Translation

An approach used in APR that views repair as a translation task to turn buggy code into correct code by training NMT models on datasets of historical bug fixes. Examples include SelfAPR, RewardRepair, Recoder, CURE, and CoCoNuT. Relies heavily on historical bug-fixing training datasets scraped from open-source repositories.
