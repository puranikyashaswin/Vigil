# Large Language Model

Models trained on billions of code and text samples demonstrating impressive performance on code-related tasks. Can be classified as decoder-only (e.g., Codex, CodeGen), encoder-only (e.g., CodeBERT), or encoder-decoder (e.g., CodeT5). Recent variants include RLHF-trained models like InstructGPT and ChatGPT.
