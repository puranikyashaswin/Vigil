# AlphaRepair

The first cloze-style (infilling-style) APR approach where buggy code is removed and an LLM directly predicts correct code given prefix and suffix context. Uses a pre-trained CodeBERT model. Demonstrated that LLM-based APR can outperform NMT-based APR techniques on real-world systems.
