# SelfAPR

A self-supervised NMT-based program repair tool that encodes bug-exposing test errors together with the original buggy code as input for APR. Uses test execution diagnostics. Achieves 64 correct fixes on Defects4j 1.2 as a baseline comparison for ChatRepair.
