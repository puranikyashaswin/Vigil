# QuixBugs

A multi-lingual program repair benchmark set based on the Quixey Challenge, consisting of 40 buggy and fixed versions of classic programming problems in both Python and Java. All 40 bugs in QuixBugs-Python are single-function, single-hunk, and single-line bugs.
