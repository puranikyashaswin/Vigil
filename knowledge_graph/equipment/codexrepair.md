# CodexRepair

An LLM-based APR tool built using the Codex model, studied in a recent extensive study of LLM-based APR techniques. Evaluated on three repair settings (single-line, single-hunk, single-function). Achieves 99 correct fixes on Defects4j 1.2 and 31 on Defects4j 2.0 as a baseline for ChatRepair.
